Fișki
Приложение для изучения румынского
Версия —
Что умеет приложение
🧠 Умное повторение — SRS-алгоритм показывает карточку ровно когда вы вот-вот забудете
✍️ Режимы учёбы — написать перевод, выбрать из вариантов, просмотр без оценки
🏃 Марафон и ошибки — все карточки подряд или только те, где вы ошиблись
🔒 Строгий режим — ответ засчитывается только с правильными диакритиками
📚 Грамматика — правила с таблицами и примерами, организованные по темам
📝 Тесты — выбор из вариантов и ввод ответа; загружай свои наборы или генерируй через нейросеть
🔤 Глаголы — тренажёр спряжений по временам с отслеживанием прогресса
📊 Статистика — история сессий, точность по дням, рекорды
💾 Импорт / экспорт — данные в JSON, легко переносить между устройствами
🎨 Темы — 6 цветовых схем на любой вкус, включая светлую
Технологии
⚡ Работает офлайн — данные хранятся в IndexedDB прямо в браузере
📱 PWA — устанавливается на экран телефона как приложение
🔒 Приватно — никаких серверов, всё только на вашем устройстве
