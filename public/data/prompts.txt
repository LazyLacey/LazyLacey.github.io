=============================================
  ПРОМПТЫ ДЛЯ ГЕНЕРАЦИИ ДАННЫХ В Fișki
=============================================

Скопируйте нужный промпт и отправьте в ChatGPT, Claude или любую другую нейросеть.
Полученный JSON сохраните как файл и загрузите в приложение.


─────────────────────────────────────────────
  1. КАРТОЧКИ
     Импорт: Настройки → Импорт данных
─────────────────────────────────────────────

Сгенерируй JSON-файл с румынскими словами по теме [ТЕМА] в следующем формате.
Верни только JSON, без пояснений.

{
  "groups": [
    { "name": "ТЕМА" }
  ],
  "cards": [
    { "groupName": "ТЕМА", "ro": "cuvânt", "ru": "слово", "note": "" },
    { "groupName": "ТЕМА", "ro": "carte", "ru": "книга", "note": "" }
  ]
}

Правила:
- "ro" — слово на румынском
- "ru" — перевод на русский
- "note" — необязательная заметка (подсказка по произношению, пример употребления); можно оставить пустой строкой
- "groupName" в карточке должен точно совпадать с "name" группы
- Можно добавить несколько групп — у каждой своё название
- ID нигде не нужны — приложение присвоит их автоматически
- При импорте выберите режим «Только слова» — он добавит карточки к существующим, не затрёт данные
- Сгенерируй [КОЛИЧЕСТВО] слов


─────────────────────────────────────────────
  2. ТЕСТЫ ПО ГРАММАТИКЕ
     Импорт: Грамматика → Тесты → Загрузить тесты
─────────────────────────────────────────────

Сгенерируй JSON-файл с тестами по румынской грамматике на тему [ТЕМА] в следующем формате.
Верни только JSON, без пояснений.

{
  "type": "testPack",
  "name": "Название пака",
  "icon": "📝",
  "description": "Краткое описание",
  "topics": {
    "topic1": { "name": "Название темы", "icon": "🏷️" }
  },
  "questions": [
    {
      "type": "choice",
      "topicId": "topic1",
      "question": "Текст вопроса?",
      "options": ["вариант1", "вариант2", "вариант3", "вариант4"],
      "answer": "вариант1",
      "explain": "Необязательное объяснение правила"
    },
    {
      "type": "fill",
      "topicId": "topic1",
      "question": "Вставьте пропущенное слово: casa ___ mare",
      "answer": "este",
      "explain": "Необязательное объяснение"
    }
  ]
}

Правила:
- "type": "choice" — выбор из вариантов (2–4 варианта в "options")
- "type": "fill" — ввод ответа вручную; регистр и пробелы по краям игнорируются
- "answer" — правильный ответ, должен точно совпадать с одним из "options" для choice
- "topicId" — ключ из объекта "topics"; если тем нет, поле можно не указывать
- "explain" — показывается после ответа, необязательно
- Сгенерируй [КОЛИЧЕСТВО] вопросов, примерно половину choice и половину fill


─────────────────────────────────────────────
  3. ГЛАГОЛЫ
     Импорт: Грамматика → Глаголы → Загрузить глаголы
─────────────────────────────────────────────

Сгенерируй JSON-файл с румынскими глаголами в следующем формате.
Верни только JSON, без пояснений.

{
  "type": "verbPack",
  "name": "Название набора",
  "icon": "🔤",
  "description": "Краткое описание",
  "tenses": ["prezent", "trecut", "viitor"],
  "pronouns": ["eu", "tu", "el/ea", "noi", "voi", "ei/ele"],
  "verbs": [
    {
      "id": "a_merge",
      "infinitive": "a merge",
      "translation": "идти, ехать",
      "group": "III",
      "forms": {
        "prezent": ["merg", "mergi", "merge", "mergem", "mergeți", "merg"],
        "trecut":  ["am mers", "ai mers", "a mers", "am mers", "ați mers", "au mers"],
        "viitor":  ["voi merge", "vei merge", "va merge", "vom merge", "veți merge", "vor merge"]
      }
    }
  ]
}

Правила:
- "tenses" — список времён для тренировки; можно использовать любые названия, главное чтобы они совпадали с ключами в "forms"
- "pronouns" — ровно 6 форм в том же порядке, что и массивы в "forms"
- Каждый массив в "forms" — ровно 6 форм (по одной на каждое местоимение)
- "group" — произвольная строка: "I", "II", "III", "IV" или "irregular"
- "id" — уникальный идентификатор глагола, латиницей без пробелов
- Сгенерируй [КОЛИЧЕСТВО] глаголов
